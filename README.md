# 🚀 HireFlow

### Full-Stack MERN Placement & Recruitment Platform

HireFlow is a modern full-stack placement and recruitment platform designed to connect students with recruiters through a streamlined job discovery, application, and candidate management workflow.

The platform provides separate experiences for **students** and **recruiters**, including job discovery, applications, saved jobs, resume management, recruitment tracking, and application status management.

---

## ✨ Features

### 👨‍🎓 Student Features

- 🔐 Student registration and login
- 👤 Profile management
- 📄 Resume upload and management
- 🔎 Job search and filtering
- 💼 Browse available opportunities
- 📝 Apply for jobs
- 🔖 Save and unsave jobs
- 📊 Track application status
- 📈 Student dashboard with application statistics
- 🎯 Profile completion tracking

### 🏢 Recruiter Features

- 🔐 Recruiter registration and login
- 🏢 Recruiter/company profile
- ➕ Create job postings
- ✏️ Edit job postings
- 🗑️ Delete job postings
- 👥 View applicants
- 📄 View candidate resumes
- 🔍 Search and filter candidates
- 🔄 Update application status
- 📊 Recruiter dashboard with hiring statistics
